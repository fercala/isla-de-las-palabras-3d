# La isla de las palabras 3D

[Jugar en GitHub Pages](https://fercala.github.io/isla-de-las-palabras-3d/)

Juego para niños de 3 a 5 años con cinco zonas, 30 misiones, Lila, Tito y Sol. Isla y personajes en 3D, cámara fija y opciones grandes; solo mouse o pantalla táctil. La dificultad se adapta por habilidad. Los logros hacen crecer la isla y los seis cuentos ofrecen dos caminos cada uno.

## Instalar en el móvil

- Android: abrir el enlace en Chrome y tocar **Instalar el juego en este dispositivo**. Si aparece una guía, usar el menú de Chrome y elegir **Instalar aplicación** o **Agregar a pantalla de inicio**.
- iPhone y iPad: abrir el enlace en Safari, tocar **Compartir** y elegir **Agregar a pantalla de inicio**.

Esperar **Listo para jugar sin internet** antes de desconectarse. Todos los recursos del mundo 3D se descargan localmente. La voz sin internet requiere una voz local en español instalada en el dispositivo.

El progreso se guarda en este navegador y dispositivo. Este origen de GitHub Pages tiene su propio guardado y no comparte los datos del enlace de Sites. Se respetan las preferencias de reducir movimientos; hay ayudas y controles para adultos, sin vidas ni tiempo límite.

## Publicación

GitHub Pages sirve la raíz de la rama main. El archivo .nojekyll permite servir los archivos estáticos directamente. Las rutas del manifiesto y del trabajador de servicio son relativas al directorio de este juego.
